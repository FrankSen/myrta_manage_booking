# 设计：界面改版、15 分钟时间档与指定时间、关闭浏览器后台下载、Mac 版

日期：2026-11-12，教练已确认。

## 1. 目标时间（方案 B）
- `Target` 新增可选 `times?: LocalTime[]`。非空 = 指定时间模式；为空或没有 = 范围模式（`timeFrom`–`timeTo`）。旧数据无此字段，按范围模式，无需迁移。
- 时间一律落在 15 分钟档上（分钟 00/15/30/45）。范围允许 `timeFrom === timeTo`，不允许倒置。
- 完全符合：范围内，或等于某个指定时间。接近：指定时间模式下偏差按最近的指定时间计算，容差 60 分钟不变。
- 界面：二选一。范围模式两个 15 分钟档下拉（06:00–18:00）；**选最早时间后最晚时间自动等于最早时间，改最晚时间不联动**。指定时间模式为可多选的时间按钮。

## 2. 界面
- 驾考风格：深路牌绿主色、L 牌黄强调、标题栏道路标线、卡片左侧信号灯色带。无外部资源。
- 顶部统计；"需要你处理"区放接近考位（改到这个时间/忽略）和已找到未提交（打开 myrta.com/继续找）。"等你确认"改名"已找到（未提交）"。
- 卡片两列对比现有预约与目标；按钮随状态。添加成功后直接打开设置目标。考点可搜索勾选列表；日期默认从现有预约日期起。运行记录可按学员筛选。

## 3. 关闭下载与 Mac 版
- 学员浏览器和界面窗口加参数关闭组件更新、模型下载、同步、安全浏览更新等后台联网；联网冒烟确认站点不拦截；对比资料目录大小。
- 打包脚本支持 `win-x64`、`mac-arm64`、`mac-x64`；Mac 包含 `启动.command`。先在本机用 Mac 包验证，再打 Windows 包。
