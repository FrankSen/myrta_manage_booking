驾考改约助手 使用手册
====================

这个软件替你盯着 myrta.com：为每个学员设定想要的考点和时间段，软件会持续刷新，
出现完全符合的考位就去改约，出现接近的考位就提醒你确认。


一、安装
--------

Windows（Windows 10 或 11）
1. 电脑需要装有 Google Chrome 或 Microsoft Edge（Windows 自带 Edge 即可）。
2. 把 myrta-rebook-…-win-x64.zip 解压到一个固定位置，例如 D:\驾考改约助手。不要直接在压缩包里双击运行。
3. 双击文件夹里的"启动.bat"。会出现一个黑色的命令行窗口，稍后自动打开软件界面。
   - 第一次运行时 Windows 可能弹出安全提示（例如"已保护你的电脑"），
     确认文件来自本软件后，点"更多信息"→"仍要运行"或"运行"。

Mac
1. 电脑需要装有 Google Chrome 或 Microsoft Edge。
   Apple 芯片（M1、M2 等）用 mac-arm64 版，Intel 芯片用 mac-x64 版。
   不确定的话：左上角苹果菜单 →"关于本机"，看"芯片"一栏。
2. 双击压缩包解压，把"myrta-rebook"文件夹拖到"应用程序"或"文稿"里。
3. 第一次打开：按住 Control 键点"启动.command"，选"打开"，再点"打开"。
   以后直接双击即可。会出现一个"终端"窗口，稍后自动打开软件界面。
   - 如果提示"无法打开，因为无法验证开发者"：打开"系统设置"→"隐私与安全性"，
     在下方找到这个提示，点"仍要打开"。

通用说明
- 黑色命令行窗口（Mac 上是"终端"窗口）是软件本身，使用期间不要关闭；关掉它，软件就停止了。
- 不需要另外安装 Node 或其他东西。
- 同一台电脑只能运行一个。如果提示"已经在运行"，说明之前开的还没关，找到那个窗口即可。


二、添加学员
------------

1. 点右上角"添加学员"。
2. 填写：
   - 备注名：给你自己看的，比如"小王 周三"，不用写全名。
   - Booking number：预约号码。
   - 姓氏：和预约上的一致（英文）。
3. 点"添加"。软件会登录一次读取学员现在的预约，大约 1 到 2 分钟，
   期间会弹出一个浏览器窗口自动操作，请不要动它。
4. 读取成功后，学员出现在列表里，显示现有预约。

如果提示读取失败，请核对 Booking number 和姓氏；也可能是网站一时打不开，过几分钟再试。


三、设置目标并开始刷新
----------------------

添加学员成功后会直接打开"设置目标"；以后也可以在学员卡片上点"设置目标"修改。

1. 目标考点：在搜索框输入考点名、地区或邮编，勾选想要的考点，可以选多个。已选的显示在搜索框下方，点 × 去掉。
2. 日期：最早日期和最晚日期。
3. 时间：考位每 15 分钟一档，有两种方式，二选一：
   - 时间范围：选最早时间和最晚时间。选了最早时间后，最晚时间会自动变成同一个时间，
     再按需要改最晚时间。最早和最晚相同，表示只要这一个时间。
   - 指定时间：点选可以接受的具体时间（例如 08:00、09:15、13:30），可多选。
     只有这几个时间算完全符合。
4. 点"保存目标"，再点"开始刷新"。状态变为"刷新中"。

刷新时每个学员会有一个自己的浏览器窗口，软件在里面自动操作。可以把它最小化，
但不要关闭，也不要在里面点击。这个窗口是必需的：myrta.com 会拦截看不见的"后台浏览器"，
只有正常打开的浏览器才能访问。

同时刷新的学员最多 2 个，每个学员大约每 2 分钟查一轮。除了你选的考点，
软件还会顺带查看附近（10 公里以内）的考点。


四、出现考位时会怎样
--------------------

完全符合（考点、日期、时间都在你设定的范围内）：
  软件自动改约，成功后学员状态变为"已改约"，并弹出桌面通知。这个学员的任务就结束了，
  如果之后还想换，请重新设置目标并开始刷新。

  说明：当前版本的自动改约还没有开启，界面顶部显示"自动改约：未开启"。
  发现完全符合的考位时，软件只走到网站的确认页，不提交，学员状态变为"已找到（未提交）"，
  出现在页面最上方"需要你处理"里，并通知你，这个学员随之停止刷新。
  点"打开 myrta.com"自己去网站改约，或点"继续找"让软件接着刷新。
  正式开启要等第一次实际改约验证完成后，届时会另行通知。

接近（时间差 1 小时以内，或考点在 10 公里以内）：
  不会自动改。"需要你处理"里会出现这个考位，同时弹出桌面通知。
  选的是"指定时间"时，时间差按离它最近的那个指定时间算。
  - 点"改到这个时间"：软件重新查看这个考位，还在就去改（自动改约未开启时同样只走到确认页）。
  - 点"忽略"：不改，继续刷新。

桌面通知：第一次打开时，点界面顶部的"开启桌面通知"并允许。


五、软件会自动停下的情况
------------------------

- 学员原来的考试距现在不到 48 小时：网站已锁定，不能再改，软件停止该学员。
- 你设定的日期范围全部进入 48 小时以内：已经没有可改的日子，停止该学员。
- 软件不会改到距现在不足 48 小时的考位。

出错时学员会变成"已暂停"，同时出现在"需要你处理"里，写明原因。
"运行记录"里有详细过程，可以按学员筛选，或勾选"只看问题"。处理后点"重新开始"即可继续。


六、常见问题
------------

问：提示"找不到 Chrome 或 Edge"。
答：安装 Google Chrome 后重新启动软件。

问：提示"站点暂时拒绝访问"。
答：网站认为访问太频繁。软件会自动让所有学员一起暂停一段时间（从 5 分钟起，最长 1 小时），
   之后自动恢复，不用处理。如果经常出现，请减少同时刷新的学员。

问：提示"站点要求验证码"。
答：软件不处理验证码，该学员会暂停。过一段时间后再点"开始刷新"。

问：提示"Booking number 或姓氏不正确"。
答：删除这个学员，核对后重新添加。

问：提示"已提交，但无法确认改约结果"。
答：请立刻用浏览器登录 myrta.com 查看这个学员的预约，以网站显示为准。

问：电脑睡眠或关机后怎么办？
答：睡眠或关机期间不会刷新。重新打开软件后，之前在刷新的学员会自动继续。
   建议刷新期间把电脑设置为不自动睡眠。

问：学员资料存在哪里？
答：存在软件文件夹里的 runtime 文件夹中，Booking number 和姓氏是加密保存的。
   不要把这个文件夹发给别人。升级软件时，保留 runtime 文件夹，替换其余文件即可。


七、关闭软件
------------

关掉黑色命令行窗口即可，软件会关闭它打开的浏览器窗口。下次打开时，
之前在刷新的学员会自动继续。
